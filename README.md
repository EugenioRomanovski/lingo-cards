# Lingo Cards — тренажёр лингвистических терминов

Веб-приложение (PWA-ready) для тренировки терминов по теоретической грамматике, фонетике, лексикологии и стилистике английского языка.

## Возможности
- 🃏 Карточки: определение → термин (ввод / выбор из 4), термин → определение (выбор из 4), **precision mode** — ввод определения с процентной оценкой близости
- 🔁 Интервальные повторения (SM-2): статусы «выучен / в процессе / слабый / пора повторить»
- ⚙️ Настройка сессии: микс тем или одна тема, 5/10/20/50/все вопросы, принудительный режим «экзамен», тумблер английских терминов
- 📚 Библиотека: поиск, фильтры, карточки терминов с этимологией и связями
- 🕸️ Граф связей терминов (Obsidian-style)
- 📈 Статистика: тепловая карта, история сессий, достижения, экспорт/импорт прогресса

## Стек
React 19 · TypeScript · Vite 7 · Tailwind CSS 3 · shadcn/ui · Zustand · Dexie (IndexedDB) · react-force-graph-2d

## Данные
`public/data/terms.json` — 264 карточки (210 RU + 54 EN), 389 связей. Прогресс хранится локально (IndexedDB).

## Локальный запуск
```bash
npm install
npm run dev
```

## Деплой
GitHub Actions → GitHub Pages (`.github/workflows/deploy.yml`). Деплой настраивается в два шага: добавить workflow через веб-интерфейс GitHub и выбрать Source = GitHub Actions в Settings → Pages.
